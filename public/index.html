    From a phone clip to a reply you'd sign

    1. 1

      Film

      The buyer tapes a sheet of A4 beside the window and films it. They can talk: "the pole should go from there to there".

    2. 2

      Find

      SAM 3.1 finds the sheet and the window in every frame and tracks the buyer's hands. Muse Voice Transcribe hears what they asked.

    3. 3

      Measure

      Plain code turns the sheet's known size into millimetres. Muse Spark picks which edges the pole spans, say a recess, and the code measures between them.

    4. 4

      Reply

      Muse Spark drafts the reply from the code's numbers. Any number that didn't come from the code or the buyer gets the draft rejected. Muse Image paints the pole on their wall.

    Checked against a steel tape

    Seven real windows in three homes, each measured by hand and filmed the way a buyer would. Where the clip isn't good enough, it says so and asks for a re-film.
