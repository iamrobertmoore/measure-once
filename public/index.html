    How it works

    1. 1

      Find. SAM 3.1 finds the sheet of paper and the window in each frame, and tracks the buyer's hands through the clip.

    2. 2

      Measure. Plain code works out millimetres from the sheet's known size. Muse Spark picks which edges the pole spans, say a recess opening, and the code measures between them and picks a pole and the cut.

    3. 3

      Reply. Muse Voice Transcribe hears what the buyer asked. Muse Spark drafts my reply.

    4. 4

      Show. Muse Image paints the pole on their wall, and SAM 3.1 cuts it out so nothing else in the photo changes.

    Every number in the reply comes from the measuring code or from the buyer's own words. The reply is checked, and rejected if it contains any other number.
